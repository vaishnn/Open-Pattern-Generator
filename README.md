# Pattern Generator Addon for Blender

Generate logos, wallpapers, signs, or anything you want with this powerful Blender Geometry Nodes addon. Create stunning circular planar patterns and animated swirling tube structures.

![Pattern Generator for Blender](https://i.imgur.com/Mrybz9f.jpeg)

This Blender addon utilizes the power of Geometry Nodes to generate beautiful and intricate circular planar patterns. Create stunning backgrounds, textures, or props for wall or neon signs and designs with ease.

## Introduction

This Blender Geometry Nodes asset allows you to create intricate, animated swirling tube structures with ease. Customize the number, shape, curvature, and animation of the tubes to generate unique and visually striking elements for your projects. The intuitive interface and robust parameter controls offer unparalleled flexibility for artists of all skill levels.

## Features

*   **Circular Planar Patterns:** Generate intricate and customizable circular patterns.
*   **Animated Swirling Tubes:** Create dynamic and visually appealing tube structures with animation controls.
*   **Geometry Nodes Power:** Leverages Blender's Geometry Nodes for procedural generation and non-destructive editing.
*   **Customizable Parameters:** Offers a wide range of parameters to control the appearance and behavior of the patterns and tubes.
*   **Easy to Use:** Intuitive interface makes it accessible to artists of all skill levels.

## Installation

1.  Download the addon from [GitHub](https://github.com/).
2.  In Blender, go to `Edit > Preferences > Add-ons`.
3.  Click `Install...` and select the downloaded `.zip` file.
4.  Enable the addon by checking the box next to its name.

## How to Use

1.  Add a new object to your scene (e.g., a Plane).
2.  Locate the Pattern Generator in the Modifier Properties of the object.
3.  Adjust the parameters to customize the pattern to your liking.
